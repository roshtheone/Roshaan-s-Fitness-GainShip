# Swipe Cricle
Swipe Circle is my showcase repository—a growing collection of web projects built with HTML, CSS, and JavaScript. Each project reflects my learning journey and evolving skills, starting with the Web Circle blog portal and expanding into future ideas.
# Web Circle – Project 1
The first project in this collection:

Built a simple online portal for tech-related blog posts.

Users can create, name, and remove their own blogs.

Focused on practicing core web fundamentals (HTML structure, CSS styling, JS interactivity).

This project was my stepping stone. At first, it felt like a burden—but now I see it as the foundation of something bigger. Web Circle marked the beginning of my habit of building, shipping, and sharing projects in public.
